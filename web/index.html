IPv6 網路設定

WAN 連線方式

依照網路業者提供的服務選擇連線方式。

固定 WAN 位址

位址與閘道須成對設定。只有使用雙協定全通道 VPN（含 ::/0）時，才可同時留空。

自動 WAN 選項

接收自動取得的 DNS 伺服器資訊。

向上游取得一個網段，再分配給 LAN 與 VLAN。

自動取得需要上游提供 IPv6 服務。使用 PPPoE 時，會在撥號成功後取得 IPv6 與委派前綴；尚未取得前綴時，不會產生區域網路的委派位址。

委派前綴設定

前綴與子網路

每個區域網路分配獨立的 /64；子網 ID 在上游更換前綴後保持不變。

子網 ID 必須各自不同；上游實際委派的前綴也需要足夠容納所有子網路。

LAN 與 DNS

LAN 使用 /64 網段，裝置可透過 SLAAC 自行取得位址。

固定 LAN 位址

最多 8 個不同位址。留空時仍可使用既有 IPv4 DNS 解析 IPv6 名稱。

VLAN IPv6 位址

為既有 VLAN 指定獨立的 /64 網段。
